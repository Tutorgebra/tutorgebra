# Contributing to TutorGebra / Cómo contribuir

**English** · [Español](#español)

Thank you for helping! Issues and pull requests are welcome: AI hallucinations, invalid GeoGebra commands, wrong math,
UI problems, and especially stricter rules for the system prompt (`app/prompts/`) from people who know the math.
